== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/memberglut` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the MemberGlut menu in your WordPress admin to configure the plugin
4. Create your first custom member role or use the built-in roles
5. Start assigning roles to your users and managing content access

== Frequently Asked Questions ==

= How do I create a custom member role? =

Navigate to MemberGlut > Roles in your WordPress admin dashboard. Click "Add New Role" and configure the role name, capabilities, and permissions according to your needs.

= Can I restrict specific content to certain member roles? =

Yes! MemberGlut includes content restriction features. You can set which roles can access specific posts, pages, or custom content types.

= What happens to existing users when I activate the plugin? =

Existing users keep their current WordPress roles. You can then assign additional MemberGlut roles to enhance their access or migrate them to custom member roles.

= Is MemberGlut compatible with other membership plugins? =

MemberGlut is designed to work independently but can coexist with other plugins. However, conflicts may occur if multiple plugins try to manage the same user roles or capabilities.

= How do I upgrade to the Pro version? =

Visit https://appglut.com to learn more about MemberGlut Pro and upgrade options. The Pro version includes advanced features like payment integration and unlimited custom roles.
